در اصل **Event Loop (حلقه رویداد)** مغز متفکر و موتور محرک برنامه‌های ناهمگام است. وظیفه آن نظارت بر کارهای در صف انتظار، سوئیچ بین تسک‌ها هنگام رسیدن به `await` و صدا زدن دوباره آن‌ها پس از آماده شدن داده است.

  

تابعی به نام `asyncio.run()` مسئول ساخت، راه‌اندازی و جمع‌آوری تمیز این حلقه رویداد است.

  

### ۱. پشت صحنه `asyncio.run()` چه اتفاقی می‌افتد؟

تابع `asyncio.run(main())` در پشت صحنه این ۴ کار را انجام می‌دهد:

  

1. بررسی می‌کند که آیا حلقه رویداد دیگری در حال اجراست یا خیر (اگر باشد، مثل خطایی که قبلاً در نوت‌بوک دیدید، خطا می‌دهد).
    
      
    
2. یک Event Loop کاملاً جدید می‌سازد (`asyncio.new_event_loop()`).
    
      
    
3. کوروتین ورودی را به عنوان کار اصلی اجرا می‌کند تا زمانی که مقدار `return` آن بازگردد.
    
      
    
4. تمام تسک‌های باقیمانده را لغو می‌کند و حلقه را به‌طور کامل می‌بندد (`loop.close()`).
    
      
    

> **قاعده طلایی:** در یک برنامه پایتون استاندارد، شما باید **فقط یک بار** `asyncio.run()` را صدا بزنید؛ آن هم در نقطه ورود اصلی برنامه:
> 
>   
> 
> Python
> ```
> if __name__ == "__main__":
>     asyncio.run(main())
> ```

### ۲. مشاهده Event Loop در کد

می‌توانید مستقیماً شیء Event Loop فعال را بگیرید و مشخصاتش را با توابع داخلی بررسی کنید:

  



```python
import asyncio

async def inspect_loop():
    # دریافت حلقه رویدادی که همین حالا در حال اجرای این تابع است
    loop = asyncio.get_running_loop()
    print("آیا حلقه در حال اجرا است؟", loop.is_running())
    print("آدرس شیء حلقه رویداد:", loop)

# در نوت‌بوک:
await inspect_loop()

# در فایل معمولی .py:
# asyncio.run(inspect_loop())
```

### تمرین‌های کدنویسی این بخش

این دو تمرین را حل کنید تا کار با چرخه حیات Event Loop و نحوه اجرای استاندارد با `asyncio.run()` تثبیت شود:

  

#### تمرین ۱: ساخت یک اسکریپت با ورودی استاندارد `asyncio.run()`

یک فایل پایتون به نام `app.py` بسازید (یا اگر در ترمینال WSL کار می‌کنید، با دستور `python app.py` اجرایش کنید):

  

1. تابعی به نام `prepare_system()` بنویسید که پیامی چاپ کند و مقدار بازگشتی `"System Ready"` داشته باشد.
    
      
    
2. تابعی به نام `main()` بنویسید که تابع قبلی را `await` کند و پیام دریافتی را چاپ کند.
    
      
    
3. در انتهای فایل، از شرط استاندارد پایتون و `asyncio.run()` برای شروع اجرای برنامه استفاده کنید:
    
      
    
    Python
    
    ```
    if __name__ == "__main__":
        asyncio.run(main())
    ```
    

#### تمرین ۲: بررسی وضعیت حلقه رویداد

تابعی به نام `check_loop_status()` بنویسید که با استفاده از `asyncio.get_running_loop()`:

  

1. زمان فعلی حلقه رویداد را با متد `loop.time()` بگیرد و چاپ کند (این زمان، تایمر داخلی خود Event Loop است).
    
      
    
2. سپس `await asyncio.sleep(1.5)` بگذارد.
    
      
    
3. دوباره `loop.time()` را چاپ کند و اختلاف زمان را نشان دهد.
    
      
    

کد تمرین‌ها را بنویسید و خروجی یا خطایی را که دیدید بفرستید تا بررسی کنی

کد شما ساختار کلی و نحوه استفاده از `asyncio.run(main())` را کاملاً درست نوشته است، اما اگر آن را اجرا کنید با یک خطای مهم پایتون روبه‌رو می‌شوید:

  

Plaintext

```
TypeError: object str can't be used in 'await' expression
```

### دو ایراد موجود در کد

۱. **استفاده از `def` معمولی به جای `async def`:** کلمه کلیدی `await` فقط روی اشیای **Awaitable** (مثل Coroutineها، Taskها و Futureها) کار می‌کند. چون `prepare_system` یک تابع معمولی است و یک رشته متنی (`str`) برمی‌گرداند، پایتون اجازه نمی‌دهد پشت آن `await` قرار دهید. باید پشت تعریف تابع، کلمه `async` را قرار دهید.
  

### نسخه اصلاح‌شده



``` Python
import asyncio

# ۱. تابع باید async باشد تا بتوان آن را await کرد
async def prepare_system():
    print("you are in the prepare_system")
    return "System Ready"

async def main():
    # ۲. ذخیره مقدار بازگشتی و چاپ آن
    status = await prepare_system()
    print("Status:", status)

if __name__ == "__main__":
    asyncio.run(main())
```

**خروجی پس از اصلاح:**

  



``` Plaintext
you are in the prepare_system
Status: System Ready
```

> **قاعده کلیدی:** هر تابعی را که می‌خواهید پشت فراخوانی‌اش `await` بگذارید، حتماً باید خودش هم با `async def` تعریف شده باشد (مگر اینکه آبجکت‌های پیشرفته‌تری مثل `asyncio.Task` یا `Future` باشد).


### مفهوم این دو دستور چیست؟

 1. اول : **`asyncio.get_running_loop()`:** تصور کنید Event Loop مثل موتور یک خودرو است. این دستور به شما دسته‌ای می‌دهد که با آن می‌توانید مستقیماً به تنظیمات و وضعیت همان موتوری که در حال کار است دسترسی داشته باشید. اگر این دستور خارج از یک تابع ناهمگام یا قبل از روشن شدن Event Loop اجرا شود، خطا می‌دهد.
    
2. دوم : **`loop.time()`:** این ساعت با ساعت دیواری سیستم (`time.time()`) فرق دارد؛ کاری به ساعت ۱۲ ظهر یا تاریخ تقویم ندارد، بلکه یک ساعت درونی یکنواخت (Monotonic) بر حسب ثانیه است که Event Loop از آن استفاده می‌کند تا بفهمد تسک‌هایی مثل `asyncio.sleep(1.5)` کِی باید دقیقاً بیدار شوند.
