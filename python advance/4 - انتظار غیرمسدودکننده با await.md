
کلمه کلیدی `await` دقیقاً نقطه‌ای است که قابلیت «غیرمسدودکننده بودن» (Non-blocking) در آن اتفاق می‌افتد؛ یعنی اجرای تابع در آن نقطه معلق می‌شود تا عملیات مورد نظر آماده شود، اما نخ اصلی برنامه (Thread) یا پردازنده فریز نمی‌شود، بلکه کنترل به **Event Loop** برمی‌گردد تا کارهای دیگر را پیش ببرد.

---

### مکانیزم کارکرد `await` در پشت صحنه

تصور کنید یک آشپز در آشپزخانه هستید:

* **حالت مسدودکننده (Blocking):** نان را داخل توستر می‌گذارید و دو دقیقه چشم به توستر می‌دوزید بدون اینکه دست به کار دیگری بزنید.
* **حالت غیرمسدودکننده (`await`):** نان را داخل توستر می‌گذارید، تایمر را فعال می‌کنید (`await toast_bread()`)، و در فاصله دو دقیقه‌ای که نان برشته می‌شود، تخم‌مرغ‌ها را هم می‌زنید. هر زمان صدای زنگ توستر آمد، برمی‌گردید و نان را برمی‌دارید.

وقتی در کد به خط `await something()` می‌رسید:

1. تابع جاری **متوقف (Pause)** می‌شود و وضعیت متغیرهای محلی‌اش در حافظه ذخیره می‌ماند.
2. کنترل کل اجرا به **Event Loop** واگذار می‌شود.
3. حلقه رویداد چک می‌کند که چه تسک‌های دیگری آماده اجرا هستند و یکی از آن‌ها را اجرا می‌کند.
4. به محض اینکه عملیات منتظرتمام شد، حلقه رویداد دوباره به سراغ تابع اول می‌آید و دقیقاً از همان نقطه به بعد ادامه می‌دهد.

---

### مشاهده رفتار غیرمسدودکننده در کد

اگر کدی بنویسیم که دو تسک همزمان داشته باشد، می‌بینید که تسک دوم دقیقاً در لحظه‌ای که تسک اول به `await` خورده و به خواب رفته، اجرا می‌شود:

```python
import asyncio
import time

async def task_one():
    print("[تسک ۱] شروع شد.")
    # کنترل به Event Loop واگذار می‌شود؛ این تسک ۲ ثانیه می‌خوابد
    await asyncio.sleep(2)
    print("[تسک ۱] بعد از ۲ ثانیه بیدار شد و پایان یافت.")
    return "نتیجه تسک ۱"

async def task_two():
    print("[تسک ۲] در حال اجراست...")
    # این تسک هم ۱ ثانیه منتظر می‌ماند
    await asyncio.sleep(1)
    print("[تسک ۲] بعد از ۱ ثانیه کارش تمام شد.")
    return "نتیجه تسک ۲"

async def main():
    start = time.time()
    
    # ساختن Task باعث می‌شود تسک‌ها بلافاصله در Event Loop ثبت شوند
    t1 = asyncio.create_task(task_one())
    t2 = asyncio.create_task(task_two())
    
    # حالا منتظر تمام شدن هر دو می‌مانیم
    await t1
    await t2
    
    print(f"زمان کل: {time.time() - start:.2f} ثانیه")

# اجرا در نوت‌بوک:
await main()

# اجرا در فایل .py:
# asyncio.run(main())

```

#### خروجی اجرا:

```text
[تسک ۱] شروع شد.
[تسک ۲] در حال اجراست...
[تسک ۲] بعد از ۱ ثانیه کارش تمام شد.
[تسک ۱] بعد از ۲ ثانیه بیدار شد و پایان یافت.
زمان کل: 2.00 ثانیه

```

**تحلیل خروجی:**

* تسک ۱ شروع شد و به `await` رسید.
* برنامه معطل نماند؛ بلافاصله تسک ۲ شروع به کار کرد.
* تسک ۲ زودتر بیدار شد و کارش تمام شد (ثانیه ۱).
* سپس تسک ۱ بیدار شد و کارش تمام شد (ثانیه ۲).
* زمان کل به جای ۳ ثانیه ($2+1$)، همان ۲ ثانیه شد.

---

### دو قانون سفت و سخت درباره `await`

1. **قانون موقعیت:** `await` فقط و فقط داخل بدنه‌ی توابعی که با `async def` تعریف شده‌اند مجاز است (استثنا: خط اول سلول‌های نوت‌بوک‌های مدرن).
2. **قانون نوع شیء (Awaitable):** هر چیزی را نمی‌توان `await` کرد. شیئی که جلوی `await` می‌آید باید یکی از ۳ نوع زیر باشد:
* یک شیء کوروتین (خروجی فراخوانی تابع `async def`)
* یک شیء `asyncio.Task` (ساخته‌شده با `asyncio.create_task`)
* یک شیء `asyncio.Future` (کارهای سطح پایین‌تر که هنوز کامل نشده‌اند)


## مورد ۴: `asyncio.run()`

### مفهوم

 اینکه `asyncio.run()` یک event loop جدید می‌سازد. بعد تابع async شما را در آن loop اجرا می‌کند. وقتی آن تابع تمام شود، `asyncio.run()` loop را می‌بندد.

این تابع معمولاً **نقطه شروع** برنامه async است. شما آن را فقط یک بار، در بیرون از توابع async، صدا می‌زنید.

### کد

```python
import asyncio

async def main():
    print("Inside main")
    await asyncio.sleep(1)
    print("main finished")

asyncio.run(main())
print("Program finished")
```

### خروجی

```
Inside main
main finished
Program finished
```

### اجرا چطور پیش می‌رود

1. `asyncio.run(main())` یک event loop می‌سازد.
2. `main()` را در آن loop اجرا می‌کند.
3. `main()` به `await asyncio.sleep(1)` می‌رسد و یک ثانیه صبر می‌کند.
4. `main()` تمام می‌شود. `asyncio.run()` loop را می‌بندد.
5. خط آخر، `Program finished`، چاپ می‌شود.

### نکته مهم

نمی‌توانید `await main()` را مستقیم در سطح اصلی فایل بنویسید. `await` فقط داخل تابع `async def` کار می‌کند. برای همین از `asyncio.run()` استفاده می‌کنیم.
